# Debt Or Investing Narrated Prototype

## Goal

Test the new no-avatar Roman Financial short format: narrator-led, image-per-chunk, slow zoom/pan, subtitles, and Fish Audio.

## Topic

Should you pay off high-interest debt before investing?

## Runtime Target

35-60 seconds.

## Format

- No avatar overlay.
- One generated image per 5-10 seconds of narration.
- Each image must represent the current narration beat.
- Style: warm pencil-and-gouache editorial finance explainer.
- Reference mood: Financial Historian-style narration structure, but with Roman Financial's own visuals and beginner-friendly personal finance angle.

## Safety

Educational content only. Avoid personalized investment advice and guaranteed returns.
